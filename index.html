System Architecture & Documentation

System Overview

FlowGrid 915 is a decentralized pipeline hydrostatic pressure telemetry and leak detection Micro-GIS portal engineered for municipal water distribution monitoring.

Hardware & Network Architecture

  • Edge Nodes: ESP32 (Heltec WiFi LoRa 32 V3) interfacing with 5V Analog Piezoresistive Pressure Transducers (0–1.2 MPa range) and MOSFET power-gating.
  • Sub-GHz Link: Raw 915 MHz LoRa point-to-multipoint star topology feeding a central Wi-Fi gateway hub.
  • Cloud & GIS Stack: Firebase Realtime Database WebSocket synchronization coupled with Mapbox GL JS vector rendering.

Operator Instructions

  • Home (Node 01): Closes active overlays and re-centers the GIS camera directly over the primary upstream reference node (dev_node_01).
  • Node Inspection: Hover over any marker on the map to view its instant status badge. Click or tap a marker to lock open its full telemetry readout (MPa and GPS coordinates).
  • Check Logs: Compiles real-time state changes across all registered pipeline nodes into a chronological audit trail.
